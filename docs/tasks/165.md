## Решения

**Триаж (2026-10-16).** Готова, вопросов нет. Все шесть пунктов критерия
проверяемы: три — прогоном теста сценария, три — чтением правленых файлов.
Имя режима в issue помечено «обсуждаемо» — выбирает план, от имени
реализация не зависит. Правленые пути (`scripts/plan.sh`, `docs/rules/**`,
`.claude/CLAUDE.md`) — группа `harness_quality` в `scripts/risk.json`, не
`harness_control`: триггер обвязки контроля не срабатывает, признак совета
«правка обвязки» — срабатывает.

**План.** Режим `bash scripts/plan.sh drift <план> <base> <head>`, дифф от
merge-base (три точки), код 0 при любом числе расхождений, явная итоговая
строка — чтобы `drift.txt` во входе совета не был пустым. Сверх критерия
issue — `drift.txt` в перечне входа режима `diff` четырёх
`.claude/agents/advisor-*.md`: определения советников перечисляют вход
поимённо, без строки советник файла не прочтёт. Развилки нет.

**Совет по плану, круг 1** — скептик, инженер, страж: `no_objections` у всех,
`unable_to_verify` пуст, `council.sh` код 0. Принят nit инженера: нет общего
предка у base и head или сбой `git diff` — код 2, а не 0 с пустым списком;
внесено в `approach` и в тест отказов.
