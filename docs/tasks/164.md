**Расхождения срезов с планом.**
- harness: проб больше контракта (формы `wsl.exe`, `cmd.exe /c`, полный путь
  `C:\…`, запись `.wslconfig` через `>>`, `Add-Content`, `Out-File`,
  `Copy-Item`); открытые формы вынесены в отдельный
  `test_wsl_working_commands_open`; `test_stand_script_allowed` проверяет и
  узость allow. Пределы deny (`-t` не первым, имя через переменную, `&` и
  `Start-Process`, `bash -c`, `-EncodedCommand`, остановка службы, сценарий
  агента) — правило, а не гарантия, запись 0026, «Пределы».
- probe: в `RouteAuthenticationAudit` сверх двух методов контракта открыты
  `Routes`, `IsDocumentedAnonymous` и константы путей — чтобы не дублировать
  положительный контроль состава маршрутов. Утверждение на ослабленном хосте
  строже плана: отказ ровно один (`ContainSingle`), то есть декоратор
  ослабляет один маршрут. Контрольный тест назван
  `UnweakenedHostPassesRouteAuthenticationAudit`.
- stand:
  - `engine()` зовёт `wsl.exe -d … --exec env DOMOVOY_STAND_SOURCE=… docker …`,
    а не `--exec docker …`: overlay нужен абсолютный путь worktree, а `.env`
    стенда держит ровно ключи `.env.example`;
  - тесты `stand.test.sh` написаны после кода — нарушение порядка
    `implement.md`, п. 2. Возмещено восемью мутациями `stand.sh`, каждая
    ловится; регрессия на поглощение stdin `wsl.exe` красная на старом коде
    (20/2) и зелёная на исправленном (22/0);
  - первый живой цикл упал (api unhealthy) — исправлено до коммита:
    `config/` стенда с umask 022 (`.env` — 077), список базовых образов через
    `mapfile` (цикл `read` терял образы: `wsl.exe` читает stdin), хвост лога
    api перед сносом при неудачном up;
  - остаток первого цикла — `moby/buildkit:v0.34.0`, вытянутый стендом, —
    срез удалил сам по ID без `-f`; потребителей не было;
  - `git -C` заменён на `cd`: при `MSYS_NO_PATHCONV=1` git.exe не понимает
    `/d/…`;
  - нечисловое имя worktree без `--name` — отказ с кодом 1, код 2 — ошибка
    вызова;
  - из 12 id реестра-примера в `demo` нет пары у четырёх (два `media_player`,
    `lock`, окно) — их перечисляет `status`;
  - `moby/buildkit:v0.34.0` — та же версия, что встроенный buildkit движка.

- rules: в `CLAUDE.md` сверх контракта — пункт «WSL общий для стенда и
  боевого стека» (п. 4 задачи, ссылкой на `implement.md`) и строка
  `compose ps` через обёртку; из живой проверки `implement.md` убраны
  `dotnet run --project src/Domovoy.Api` (в `Development` читает
  user-secrets владельца) и пример `docker compose up` + `curl :18080`
  (боевой проект и порт).

**A-memory (2026-10-16).** Память `live-check-throwaway-stand` переписана:
вместо пересказа — ссылка на `docs/rules/implement.md`, «Живая проверка — на
стенде»; строка указателя в `MEMORY.md` — «правило в docs/rules/implement.md».
Файл памяти вне репозитория.

**A-df: условие «чужой активности нет» (решение оркестратора, 2026-10-16).**
Буквально невыполнимо: healthcheck работающего боевого стека всегда даёт
`exec`-события. Принято: условие выполнено, если среди чужих событий нет
create, start, stop и destroy объектов, а только `exec` healthcheck. Окно
`docker events` демона неполное (первые ~3 мин вытеснены буфером) — сумма
`system df`, тома боевого проекта и список CACHE ID сверены отдельно и
совпали.
