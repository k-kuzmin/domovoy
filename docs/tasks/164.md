- harness: проб больше контракта (формы `wsl.exe`, `cmd.exe /c`, полный путь
  `C:\…`, запись `.wslconfig` через `>>`, `Add-Content`, `Out-File`,
  `Copy-Item`); открытые формы вынесены в отдельный
  `test_wsl_working_commands_open`; `test_stand_script_allowed` проверяет и
  узость allow. Пределы deny (`-t` не первым, имя через переменную, `&` и

  `Routes`, `IsDocumentedAnonymous` и константы путей — чтобы не дублировать
  положительный контроль состава маршрутов. Утверждение на ослабленном хосте
  строже плана: отказ ровно один (`ContainSingle`), то есть декоратор
  ослабляет один маршрут. Контрольный тест назван
  `UnweakenedHostPassesRouteAuthenticationAudit`.
- stand:
  - `engine()` зовёт `wsl.exe -d … --exec env DOMOVOY_STAND_SOURCE=… docker …`,

    срез удалил сам по ID без `-f`; потребителей не было;

    вызова;
  - из 12 id реестра-примера в `demo` нет пары у четырёх (два `media_player`,

`system df`, тома боевого проекта и список CACHE ID сверены отдельно и
совпали.
