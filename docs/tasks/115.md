## Решения

Решения и отвергнутые варианты — раздел 2 плана круга 3. Здесь — то, что
принято по ходу реализации.

**Сначала красный.** Сценарий «Анонимный эндпоинт опознаётся словом
allowanonymous…» до правки конфига падал по существу: `Уровень: low`, сигнала
`sensitive-area` нет, строки `слово: AllowAnonymous — …` нет (харнесс 39 из 40).
После правки — 40 из 40.

**Контрольный прогон без слова — через `mutate_config`.** Конфиг настоящий, из
него вычитается ровно `allowanonymous`: молчание на том же диффе доказывает,
что high держится на слове, а не на чужом совпадении в тех же строках.

**Размер плана: сначала красный.** Три сценария до правки движка падали по
существу (харнесс 39 из 42): план на 12 файлов давал `low` без `diff-size`,
незаданный порог файлов в plan молчал, строки «по строкам» в выводе не было.
После правки — 42 из 42. Текст «Не измерялось в режиме plan» сохраняет
«размер диффа» и «ключевые слова» и называет строки: «размер диффа по строкам
и ключевые слова по добавленным строкам … Размер по числу файлов считается по
files[] плана».

**Строка о незаданном пороге размера в plan — по порогу файлов.** Диффу нужны
оба порога, плану — только `diff_files`: строк у него нет, и незаданный
`diff_lines` на счёт плана не влияет.
