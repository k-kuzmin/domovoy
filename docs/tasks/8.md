## Решения

**Триаж (2026-10-12).** Вердикт `ready: false`, два вопроса. Ссылки на ТЗ
(AR-5, 5.1.3) существуют, противоречия с правилами проекта нет.

- Место бэкапа. Владелец (2026-10-12): **внешний диск / USB**, подключённый к
  хосту. Новых зависимостей нет; путь задаётся конфигурацией, в README —
  только плейсхолдер.
- Среда проверки восстановления. Владелец (2026-10-12): **тот же хост, пустые
  тома** — отдельный проект compose с чистыми томами, восстановление из
  последнего бэкапа, проверка: HA видит устройства, Backend видит свои данные.
- Хост — Windows 11 (ответ владельца по #6); расписание — средствами хоста.

**Совет по плану, круг 1 (2026-10-12).** Страж и инженер — `no_objections`,
скептик — `another_round`; `council.sh` — код 0, блокеров нет, принято 7
замечаний (2 major скептика, 5 nit), все внесены в план шагом плана.

**Опыт к major скептика «HA в internal-сети не даст состояний» (2026-10-12).**
Агенту запуск копии тома HA закрыт классификатором прав; сценарий прочитан
оркестратором и запущен владельцем через `!`. Копия тома HA (рабочий том
только на чтение, без базы рекордера) в `--internal`-сети, HA 2026.10.1:
реестр — 73 записи, не отключённых — 59; в `/api/states` присутствуют
**59 из 59**, из них `unavailable` — 45; недостачи по платформам нет.
Правило «N из N» остаётся без ослабления, замечание снято.
