## Решения

**Триаж — готова, вопросов нет (оркестратор, 2026-10-22).** Пути из «Где
смотреть» существуют (`FastPathRunner.cs`, `ReadValueTemplate.cs`,
`HaWebSocketProtocol.cs`), сущность `climate.example_bedroom_ac` есть в
`config/entities.example.yaml`. Объём — одно изменение ветки `read` раннера.
Способ проверки по пунктам: (1) и (2) — модульный тест раннера на
`climate.example_bedroom_ac` с атрибутом `current_temperature`, ожидается
полезная нагрузка с числом и единицей; (3) — тест без атрибута, ожидается
отказ; (4) — существующие тесты чтения `sensor` и полный `dotnet test`
зелёные. Вариант для пункта 3 критерий оставляет исполнителю — не вопрос
владельцу.

**Нет `current_temperature` — отказ, а не режим.** `Success = false`, текст
«Устройство не сообщает текущую температуру.», `ErrorCode = null`: на вопрос
«сколько градусов» режим не ответ, а успешный результат с режимом читался бы
как ответ. Отказ без кода `ToolResult` допускает (`ToolResult.cs`, «`null` —
успех или отказ без кода»); на провод отказ раннера пока не выходит.

**Единица — °C.** Проект уже исходит из Цельсия: границы `set_temperature`
7..35 — DEFAULT_MIN_TEMP и DEFAULT_MAX_TEMP Home Assistant
(`src/Domovoy.Ha/Registry/HaDomainCatalog.cs:224`). Спросить не у кого —
принято это допущение; имперская система единиц — отдельная задача.

**Атрибут выбирает раннер по домену, а не шаблон по вопросу.** Для нынешних
формулировок наблюдаемый результат тот же: вопрос о режиме до `climate` не
доходит — сущность выбирается по словам имени, слова «режим» в именах нет.

## Отвергнуто

- Режим с пометкой при отсутствии атрибута — успешный результат с режимом
  маскирует отсутствие данных.
- Новый код в `HaErrorCodes` — те же строки идут в `ApiError.Code`, это
  расширение контракта ради отказа, который на провод не выходит.
- Единица из `/api/config` Home Assistant — лишний вызов ради системы
  единиц, которой в проекте нет.
- Поле атрибута в `FastRouteMatch`, выбор в шаблоне — тот же наблюдаемый
  результат ценой поля модели ядра и правки двух шаблонов.

  корректность пропущено — правка в одном методе, контракт приёмки покрыт
  тестами.
