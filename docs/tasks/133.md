## Решения

**Триаж (2026-10-07).** Шаг триажа вернул `ready=false` с пятью вопросами;
оркестратор сверил их с репозиторием, четыре сняты фактами или отнесены к
плану, один ушёл владельцу:

- слова чувствительной зоны (пункт 4) — оценка триажа «выражается конфигом
  через `prefixes`» оказалась верной лишь частично: шаг плана и проверка
  оркестратора тем же awk показали, что левая граница не находит корень внутри
  составного идентификатора (`clientsecret`, `AddAuthentication` — нет,
  `secrets` — да). Остальное — развилка карточки плана;
- пункт 11 — оценка триажа «покрыт `*Info.plist` в `risk.json`» неверна по
  месту: пункт про гейт, а `risk.json` даёт только уровень; в списке подписей
  `scripts/guard-lite.sh` имени нет — правка гейта в плане;
- пункты 2–3: проекта `Domovoy.Mobile.App` ещё нет, но раскладка закреплена
  записью 0013 — шаблоны на будущие пути возвращаются;
- формат тестов прав (пункты 12–14) — решение плана.

Вопрос владельцу — объём выше порога `size.files` (около 13 файлов при 11) и
пять подсистем: один PR, вынос миграций или пять задач. Ответ владельца — **один
PR**; часть 3 (миграции, блокер первой EF-миграции) идёт первыми коммитами.

**Развилка п.4 и просмотр плана (2026-10-07).** Владелец посмотрел план после
совета и ответил:

- п.4 — отказ записывается здесь: корень слова внутри составного
  идентификатора (`clientSecret`, `AddAuthentication`) и фраза с пробелом
  конфигом `scripts/risk.json` не выражаются, `scripts/risk.sh` не правится.
  Формы с начала идентификатора возвращаются;
- п.13 — расширить: кроме вариантов `.env` закрыть правами локальные файлы
  конфигурации, которые `.gitignore` держит как файлы с секретами
  (`appsettings.{Development,Production,Local}.json`,
  `docker-compose.override.{yml,yaml}`); план исправлен;
- реализацию начинать; по просьбе владельца — параллельными срезами.

**Реализация (2026-10-07).** Четыре параллельных среза в отдельных worktree —
гейт (п.6–11), `risk.json` (п.1–4), инвариант числа тестов (п.5), права
(п.12–14); файлы срезов не пересекаются, склейка — cherry-pick в порядке
гейт → риск → инвариант → права, без конфликтов. Решения по ходу:

- уровень на смерженном #102 по новому конфигу вырос с medium до high —
  строки `secrets.…` и `persist-credentials` в workflow. Сузить форму нельзя:
  после `tolower` такая строка неотличима от `Secrets;` в коде. Принято как
  верный сигнал — прокидывание секретов в CI чувствительно, а `risk.sh` только
  ужесточает маршрут, ничего не блокирует. `words_skip_paths` не расширялся;
- фикстура п.7 снята настоящим `dotnet ef migrations add` (EF Core 8, Npgsql
  8.0.11): EF ставит `#pragma warning disable` и в основной файл миграции на
  многострочном seed — исключение по каталогу `src/Domovoy.Data/Migrations/`,
  а не по именам `*.Designer.cs`/`*ModelSnapshot.cs`, подтверждено;
- п.6 строже плана: переименование `tests/…*.cs` в не-`*.cs` тоже нарушение;
- п.9: при неопределённой границе разметка `Down()` сбрасывается и весь файл
  проверяется правилами `Up()`; препроцессорные строки пропускаются;
- п.10: шаблон `TestCaseFilter` построчный — разнесённый по строкам элемент
  не ловится; предел назван, в объём п.10 не входит;
- п.13: закрыты и правка `.env`, и правка его вариантов — критерий p13 «на
  чтение и правку»; локальная конфигурация закрыта пятью явными именами из
  `.gitignore`, без `appsettings.*.json`, чтобы не закрыть будущий
  отслеживаемый файл;
- снимок числа тестов — 55 по локальному прогону; сверка с ubuntu — ручной
  запуск `ci-fast.yml` на ветке до PR. Инвариант краснеет и на рост: PR с новым
  тестом правит снимок в том же диффе.
