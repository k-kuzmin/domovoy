## Решения

**Триаж (2026-10-12).** Вердикт `ready: false`, два вопроса. Пути и ссылки на
ТЗ (5.1.2, 5.1.3, REPO-4) существуют, противоречия с правилами проекта нет.

- Вопрос триажа «где наблюдать статус „не сконфигурировано“ без токена» снят
  оркестратором по коду, владельцу не задавался: незаполненный секрет даёт
  `ComponentState.NotConfigured` → `HealthStatus.Degraded`
  (`src/Domovoy.Api/Health/ComponentsHealthCheck.cs:73`), анонимный `/health`
  отдаёт его как `{"status":"degraded"}`, а отказ — как `unhealthy`. Способ
  проверки — `curl -s http://localhost:8080/health` на чистом окружении.
- Объём: оценка 6–10 ч при правиле «больше 8 ч — дробить». Владелец
  (2026-10-12): вести **одним PR**. Если прогон на чистом окружении вскроет
  больше расхождений, чем укладывается в PR, — разбиение предлагается тогда.

## Отвергнуто

- Порт 8088 и «только в локальном `.env`» — владелец выбрал 18080 дефолтом
  проекта.
- Смена порта отдельной задачей — владелец выбрал #5: те же файлы, один PR.

- Расширить анонимный `/health` деталями компонентов — расходится с записью
  [0002](../decisions/0002-split-health-endpoint.md) и не нужно: `degraded`
  уже отличает «не сконфигурировано» от отказа.

**Совет по плану, круг 1 (2026-10-12).** Скептик, инженер, страж — все
`no_objections`, блокеров нет, четыре nit приняты и внесены в план: доказательство
подъёма — `--wait` и `compose ps --format json`, а не grep выравнивания лога;
README про 401 — «на этапе каркаса»; `RestartCount` сверяется пятью прогонами
до PR; PR не открывается без вывода прогона 2 в «Проверено».

**Порт API на хосте: 8080 → 18080 (2026-10-12).** Владелец: «порт 8080 надо в
целом освободить. его использует мсп для unity движка». На хосте 8080 делят
Docker Desktop (`0.0.0.0`) и `wslrelay` (`[::1]`) — `curl localhost:8080` может
уйти по IPv6 не в стек. Владелец выбрал 18080 и сделать это в #5, а не
отдельной задачей. Порт внутри контейнера остаётся 8080. План расширяется,
совет по плану — круг 2.

**Живые прогоны делает владелец.** Агенту создание `.env` закрыто правами, даже
во временном клоне; прогон во втором клоне на хосте отвергнут — совпали бы
имя проекта, порт и том рабочего стека.
