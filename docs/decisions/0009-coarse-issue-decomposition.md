# 0009. Декомпозиция крупными задачами вместо дробления до 2–8 часов

**Статус:** принято

## Решение

Этапы 0–6 заведены задачами уровня подсистемы. Каждая крупная задача
несёт оценку диапазоном и пометку, что дробится на подзадачи перед
началом своего этапа.

## Почему так

Решение владельца проекта. Основание, которое подтверждает и само ТЗ:
промпт и набор инструментов будут переписываться ежедневно первые
недели. Подробные задачи на этапы 4–6, написанные сейчас, устареют
раньше, чем до них дойдёт дело, — и их придётся переписывать вместе с
доской, а не вместо неё.

## Следствия

- Оценка сроков по доске возможна только по диапазонам, не по сумме
  часов.
- Перед началом каждого этапа задачи этого этапа дробятся. Дробление —
  часть работы над этапом, а не отдельная задача.
