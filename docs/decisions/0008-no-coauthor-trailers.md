# 0008. Запрет трейлеров соавторства проверяется хуком

**Статус:** принято

## Решение

Сообщения коммитов не содержат трейлеров `Co-Authored-By`, упоминаний
генерации и подписей инструментов. Запрет проверяется механически в двух
местах: хук `commit-msg` отклоняет коммит локально, отдельная работа в CI
проверяет всю историю.

## Почему так

Часть инструментов добавляет такой трейлер автоматически, по умолчанию,
без явного действия автора. Правило, которое нарушается настройкой по
умолчанию, дисциплиной не держится — оно держится проверкой.

Проверка истории в CI, а не только последнего коммита: трейлер,
попавший в середину серии, иначе останется незамеченным до тех пор, пока
кто-нибудь не прочитает лог целиком.

## Следствия

- Хук `commit-msg` проверяет заодно и Conventional Commits: два правила
  формата сообщения удобнее держать в одном месте.
- Хуки не подключаются к клону сами. Нужна однократная команда
  `git config core.hooksPath .githooks`; она указана в README и
  `.claude/CLAUDE.md`, а CI страхует случай, когда её не выполнили.
