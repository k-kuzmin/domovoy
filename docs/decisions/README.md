# Решения

Здесь фиксируются решения, расходящиеся с ТЗ или не выводимые из него.

Причина простая: через месяц по коду не отличить принятое решение от
недосмотра. Запись отвечает на вопрос «это так специально?» — и тем
самым избавляет от повторного обсуждения.

Запись появляется, когда:

- решение расходится с буквой ТЗ;
- выбран один из нескольких равноправных вариантов, и выбор неочевиден;
- новому публичному эндпоинту разрешён анонимный доступ;
- добавлена зависимость вне минимального набора.

Формат: `NNNN-краткое-название.md`. Записи не переписываются — решение,
которое отменили, получает новую запись со ссылкой на прежнюю.
