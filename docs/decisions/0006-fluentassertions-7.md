# 0006. FluentAssertions закреплён на версии 7.x

**Статус:** принято

## Решение

`FluentAssertions` закреплён на 7.2.2. Обновление до 8.x требует
отдельного решения.

## Почему так

Начиная с версии 8.0 FluentAssertions распространяется под платной
лицензией для коммерческого использования. Версия 7.x остаётся под
Apache 2.0.

Проект публичный и под MIT, то есть под условия бесплатного
использования 8.x он, скорее всего, попадает. Но «скорее всего» —
неподходящее основание для зависимости в публичном репозитории, который
кто-то может использовать как образец. Разница в возможностях между 7.x
и 8.x для наших проверок несущественна.

## Следствия

- Автоматическое обновление до 8.x недопустимо: версия закреплена точно,
  в `Directory.Packages.props`, с комментарием о причине.
- Если 7.x перестанет поддерживать актуальный .NET, вопрос
  пересматривается отдельной записью.
