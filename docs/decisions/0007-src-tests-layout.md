# 0007. Проекты разложены по `src/` и `tests/`

**Статус:** принято

## Решение

```
src/    Domovoy.Api, Domovoy.Core, Domovoy.Ha, Domovoy.Llm,
        Domovoy.Voice, Domovoy.Notifications, Domovoy.Data
tests/  Domovoy.Tests
```

Раздел 0 ТЗ перечисляет проекты, но не задаёт раскладку по каталогам.

## Почему так

Разделение продуктового кода и тестов на уровне каталогов даёт две
вещи, которых нет при плоской раскладке: путь файла сразу говорит,
продуктовый это код или тестовый, и правила `.editorconfig` для тестов
задаются секцией `[tests/**/*.cs]`, а не перечислением имён проектов.

## Следствия

- `Dockerfile` копирует файлы проектов по этим путям, поэтому
  переименование каталогов ломает кэш слоёв сборки.
- Команды миграций в README и `.claude/CLAUDE.md` содержат путь
  `src/Domovoy.Data`.
