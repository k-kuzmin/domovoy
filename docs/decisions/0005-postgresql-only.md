# 0005. PostgreSQL без варианта SQLite

**Статус:** принято
**Расходится с:** раздел 3 ТЗ

## Расхождение

Раздел 3 ТЗ допускает «PostgreSQL (или SQLite на старте)». Минимальный
набор библиотек разрешает только провайдер PostgreSQL.

## Решение

PostgreSQL с первого дня. Вариант SQLite не реализуется.

## Почему так

Поддержка двух провайдеров EF Core — это не одна лишняя зависимость, а
второй набор миграций, различия в типах и поведении при конкурентном
доступе, и удвоенная матрица тестов. Выигрыш при этом нулевой: Postgres в
compose поднимается одной строкой и на целевом железе (16 ГБ RAM)
незаметен.

«SQLite на старте» экономит настройку, которой в этом проекте нет.

## Следствия

- Единственный провайдер — `Npgsql.EntityFrameworkCore.PostgreSQL`.
- Локальная разработка требует запущенного контейнера базы. Без него
  `/health` покажет для БД «недоступна», приложение при этом поднимется.
